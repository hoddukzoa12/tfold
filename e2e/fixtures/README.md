- `callouts/` is original content written for this repository, under the repository's AGPL-3.0 license. It is a page with no `article` or `main` whose blocks paint their own text on their own background, light by default and dark under `prefers-color-scheme: dark`. - `themes/` is original content written for this repository, under the repository's AGPL-3.0 license. Its theme is a class on `<html>`, `theme-light` or `theme-dark`, that sets the page's colors through custom properties, as WordPress and Tailwind themes do. `#plain` paints no background of its own. `#wp-note` is a WordPress-style note, `class="has-background"` with its background in the `style` attribute and its text color inherited, and `#wp-preset` takes its background from a WordPress-style preset class whose rule is `!important`, with its text color inherited. `#theme-id` takes its background from a rule on its id and holds `#term`, whose class `term-plain` or `term-marked` sets its colors. `#panel` is a wrapper with a theme class of its own, `panel-light` or `panel-dark`, around a plain paragraph and a note. `<style id="dusk" media="not all">` turns the tint of `#theme-id` yellow once its `media` attribute matches. A disabled `<style id="night">` turns the page dark when a script enables its sheet, a change that touches no element.

`npm run fixtures:capture` captures the three saved pages again. Name a fixture directory after `--` to capture only that page, such as `npm run fixtures:capture -- arxiv-2401.04088`. It removes scripts, inline event handlers, frames and preload links, inlines every stylesheet, turns logos and photos into gray boxes, and saves the remaining images and the fonts under each page's `assets/`. It drops Adobe Fonts stylesheets, whose license does not allow redistribution, so text in those families falls back to the next font in the stack. It fails when the saved page still requests a URL off the fixture server.
